# Website-Project
The Travel Guide Hub

A university group web development project built with HTML, CSS, JavaScript, and jQuery. The website lets users explore travel destinations, compare holiday packages, and submit enquiries through an interactive, user-friendly interface.

# My Contributions
Designing and developing the Home and Destinations pages.
Contributing to group wireframes and website planning.
Selecting the website's colour scheme and maintaining consistent CSS styling.
Implementing interactive destination filtering using jQuery.
Implementing newsletter email validation using JavaScript and jQuery.
Testing navigation links, filtering functionality and newsletter validation.
Technologies Used: HTML5, CSS3, JavaScript and jQuery.

# Team Project
This project was developed collaboratively by four students at Ulster University. Other team members contributed to additional website pages and functionality.
